New Life v0.4 新版说明

1. 音频自动跟随 Windows。在设置中选择“我听声音的耳机／扬声器”和“我说话的麦克风”，或点击“打开 Windows 声音设置”。在软件内更换会同步修改系统，影响其他软件；退出后保留，不再自动恢复。
2. 本人讲话请选择真实麦克风。CABLE Output 是通话软件给对方听声音所用的输入，不是你本人讲话的设备。电脑录音跟随当前系统扬声器；虚拟通话设备自动检测。
3. 点右下角“分享给通话对方”开启分享，按钮会显示“正在分享 · 点击关闭”。关闭只停止分享片段，本人讲话继续；彻底断开在通话设置中操作。
4. 点“选择文件夹”更换目录；旁边只显示文件夹名称，点击名称打开该目录。
5. 设置→常规→界面配色可选跟随系统、深色、浅色，立即生效，不打断播放或录音。
6. 列表勾选框整块区域都可以点，波形底部进度轨道可点击或拖动。上方两端把手调整播放范围，二者互不触发播放。
7. 新设备在使用音频期间无法识别时，会提示停止录音、断开通话后重新检测，不会假装切换成功。更换设备可能短暂中断声音，录音文件继续保存。
8. Windows声音设备默认修改长期保留，包括通话设置中的“设置通话麦克风并连接”；旧恢复记录归档，不在退出或下次启动时恢复。

New Life v0.4.0 — Windows 11 x64

运行：解压整个文件夹，双击 NewLife.exe，保留旁边的 _internal 和 vendor；无需安装 Python 或 FFmpeg。

1. 点击文件夹按钮选择目录，只显示直接包含的媒体，不递归扫描子文件夹。支持 WAV、MP3、FLAC、OGG、Opus、M4A、M4B、AAC、WMA、AIFF、APE，以及 MP4、MKV、MOV、WebM、AVI、WMV、FLV、TS、MTS、M2TS、M4V、VOB、MPEG、3GP。视频只播放声音，多音轨可在右键菜单选择。
2. 点击头像／名称播放，再点同一个声音停止。波形左键不会触发播放；拖动左右边界至少保留1秒，可以边播放边调整，原音频完整保留。
3. 波形底部的播放进度条可以拖动定位；只对当前播放或暂停的条目生效，不改变左右播放范围。右键可另存、精确输入时间、改名、设置图片或快捷键。图片拖到头像处打开方形裁剪，拖到行背景打开背景裁剪；支持拖动、缩放、重置和重新裁剪，取消不改变原设置。
4. 主窗口可选择电脑、麦克风或都录制；录音时标记起点／终点，闭合的片段立即可用。录音期间不能换文件夹或进入迷你条。
5. 迷你条为一行，头像名称点击播放／停止；目录和音量向下展开。长名称悬停查看；音量支持滚轮。
6. 隐藏到托盘与 × 退出是两个独立按钮。隐藏保持录音、通话及快捷键；退出先完成录音保存，再断开通话，保留系统设备设置。托盘也提供退出入口。
7. 右上角中文／EN立即切换并保存；名字和设备名称不会被翻译。
8. 外部音频、视频拖入列表或空白区会复制到当前播放文件夹，原文件保留，同名自动加序号；视频复制原视频，不另外提取音频。默认文件夹里的文件再次拖入只刷新。
9. 序号前的复选框支持批量选择，表头全选，Shift 连选，列表获得焦点时 Ctrl+A 全选当前结果。删除前统一确认，文件及其配置一起移到回收站；失败逐项提示，不永久删除。
10. 设置过的媒体旁有“原文件名.ext.newlife”配置包，包含头像与背景原图、裁剪、颜色、播放范围、音轨及快捷键。换电脑时一起复制媒体和配置包即可恢复；单独复制媒体无法携带外观。设备和列表排序留在本机，快捷键冲突会暂时停用并保留原定义。

通话配置：
安装VB-CABLE：访问 https://vb-audio.com/Cable/ ，下载后以管理员身份安装并重启。
播放器自动检测标准 CABLE Input (VB-Audio Virtual Cable)；设置中只需确认真实麦克风和本地耳机。
微信／QQ／Discord或游戏的输入设备选择 CABLE Output (VB-Audio Virtual Cable)。主界面开启“分享给通话对方”会连接通话链路并发送片段；关闭分享只停止发送片段，本人讲话继续；在设置里“断开通话”才会停止整条链路。
设置→通话中的测试声音用于让对方确认。发送电平只说明播放器已送出声音。
“设置通话麦克风并连接”会更改Windows默认通信麦克风并长期保留；软件内部固定选择的麦克风仍要手动修改。
断开通话或退出后保留系统设备设置；在 Windows 手动修改后，软件继续跟随。
仅在你选择更换设备时修改系统默认耳机或麦克风；不调整音频增强、系统音量或Windows麦克风侦听，不静默安装驱动。

听到自己的声音：检查Windows麦克风属性→侦听→侦听此设备，以及声卡软件的侧音／监听。默认软件不监听本人麦克风。
录音卡顿：查看通话设置中的缓冲、溢出和丢帧诊断。设备断开不会自动切到其他设备，请重新选择。
正在录音或连接通话时，新接入设备可能暂不出现；结束录音和通话后刷新设备。

实际格式以文件内容为准。改扩展名不会转换格式；没有音轨、损坏、权限不足或不足1秒会显示原因。只读目录可以读取，便携配置无法保存时会明确提示。

本机配置和日志：%LOCALAPPDATA%\NiuLaiPlayerPython（为兼容旧数据保留目录名）。
音频：你选择的文件夹。升级前自动备份配置数据库；请自行备份原音频。
