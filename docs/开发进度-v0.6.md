# New Life v0.6 开发说明

本轮将已确认的布局和交互落实到Python桌面软件，旧版发布包及源代码备份保留。

| 本次做了什么 | 关键代码 | 怎样验证 |
|---|---|---|
| 顶部两排、底部对齐、精简播放列、统一表头 | `ui.py`、`style.py` | 切换中英文和深浅配色，缩小窗口，检查控件是否对齐、可操作 |
| 帮助和快捷键独立面板，入口再次点击关闭 | `ui.py` | 打开、关闭、切换面板；快捷键草稿保留，关闭后后台快捷键恢复 |
| 波形中央轴、已播放颜色与单个进度圆点 | `widgets.py` | 播放时拖动圆点，调整范围；当前位置始终在范围内，编辑不误播 |
| 文件导入结果、删除撤销、分别重置外观及范围 | `controller.py`、`library.py`、`file_undo.py` | 用示例目录测试成功、失败、同名冲突与撤销，不使用自己的唯一音频 |
| 录音状态和新录音定位 | `controller.py`、`ui.py` | 检查来源锁定、累计时间与结束保存，新文件高亮而非自动播放 |
| 发布包与教学 | `build.ps1`、`tools/verify_release.py`、开发教学第十三课 | 运行测试后打包，使用独立配置检查冻结EXE |

本次练习重点是把一条需求拆成“看起来如何、点击后如何、出错后如何恢复”，再为每部分提供可复现的验收。最终测试数量及发布包信息以根目录`VALIDATION.md`为准。

v0.6.1仅调整主列表头像：`AvatarButton.paintEvent()`将显示尺寸从28改为40逻辑像素，并把名称和播放提示排在右侧。裁剪仍使用保存的原图与坐标，显示放大不需要重新配置头像；迷你条保持28像素。练习时可比较显示尺寸与图片文件尺寸，理解界面绘制和用户数据保存是两件事。
