# New Life v0.5 开发说明

本次围绕三个可验证结果：迷你条可以拖动且不误播；常用设置在顶部直接操作；MUSIC随程序携带。

- 关键代码：ui.py的MiniWindow/MainWindow和嵌入设置面板，controller.py的轻量设置接口，music_folder.py的根目录解析，build.ps1的发布目录复制。
- 操作验证：按住迷你头像移动，再普通单击；顶部换主题和置顶；展开通话帮助与快捷键；从其他文件夹运行程序，打开MUSIC。
- 学习顺序：先看行为，再给事件入口设断点，观察共享状态，运行隔离测试，最后打包检查。具体练习见《开发流程与练习》第十二课。
- 旧音频、配置、发布包保留；MUSIC目前留有说明，待录制自带音频后参与打包。

最终测试和发布验证结果见项目根目录VALIDATION.md。
