# New Life v0.5.0 验收记录

日期：2026-10-03。Windows 11 x64、Python 3.13.15。系统设备修改继续采用长期保留，退出不恢复。

## 本次改动

- 迷你条仍为380×48。头像、名称及空白处可拖动；超过系统拖动阈值后取消本次按钮点击，释放或隐藏后清除拖动状态，正常单击仍播放／停止。
- 主窗口顶部直接提供真实麦克风、耳机／扬声器、主题、迷你置顶；状态同步不会反向修改系统设备，主题／置顶仅保存界面状态，不重启音频链路。置顶变化保留迷你窗口位置与显示状态。
- 通话帮助与快捷键替换设置齿轮，在主窗口内共用一个可滚动折叠区域。快捷键保存只提交快捷键，保留草稿；收起、隐藏、迷你、退出及页切换恢复捕获，单片段快捷键编辑与面板焦点互不解除对方的暂停。
- 设备下拉框只省略绘制文字，保留完整名称、设备标识及下拉选项；图标悬停提示在刷新与中英文切换后保持正确。英文主题与模式标签完整显示。
- 开发默认项目根MUSIC，冻结版默认EXE旁MUSIC，不使用工作目录或_internal。已有有效自选文件夹保留，缺失目录明确提示；不可写目录仍可试听，录音、导入、另存及配置写入给出具体错误。
- 发布只加入根MUSIC直接媒体、配套.newlife和说明，重建时不遗留源目录已经删掉的音频。当前MUSIC仅有说明.txt，等待用户录制自带音频；个人录音未加入发布包。
- 修复配置保存状态竞态：读取旧配置不清除写入失败，并发旧读取不回滚新编辑或配置版本；原包保留，显式重试成功后才显示保存成功。
