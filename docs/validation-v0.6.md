# New Life v0.6.0 验收记录

日期：2026-10-04。Windows 11 x64、Python 3.13.15。旧发布包、音频及配置目录保留；修改前源码备份在 `artifacts/source-before-v0.6.zip`。系统设备修改继续长期保留，退出不恢复。

## 已实现的行为

- 主窗口顶部两排，按钮使用固定比例；序号在前、勾选框在后，合计58逻辑像素。播放区域宽150像素，780宽窗口下为120像素，其余空间给播放范围。六列表头与内容居中对齐，滚动条出现后仍保持列位置一致。
- 录音和通话按钮等宽、上下对齐；状态和 `Bilibili那年松江` 并入底部。设备和隐藏图标清楚，语言按钮直接切换。英文固定选项完整显示，复选框边框与整块点击区域匹配。
- 通话帮助、全局快捷键、片段快捷键、精确范围、导入结果均为独立非模态面板。同入口再次点击关闭，切换面板保留草稿；关闭编辑后恢复后台快捷键。缩放适配计算可用工作区与窗口装饰边框，保留顶部入口。
- 波形中央2像素横轴显示绿色已播放、灰色未播放，只有一个圆点表示当前位置。圆点及横轴都在范围内；定位和范围把手分别命中。最短1秒，松手提交，Esc取消；点击时间可精确编辑，其他音频行不会定位当前声音。
- 导入摘要及详情来自真实逐文件结果，即时翻译保留文件名。可分别恢复默认头像、背景及完整范围，旧裁剪任务不能覆盖重置结果。
- 最近一批删除30秒内可撤销，继续删除会替换上一批机会。音频和便携配置成对暂存、同名不覆盖；恢复与扫描／配置写入互斥。到期或退出整批移入回收站，失败保留恢复记录；历史异常退出记录不因普通退出自动回收。仅空目录清理失败仍正确报告音频恢复成功。
- 录音显示来源、红点与累计时间，来源锁定；结束保存后新文件高亮并滚动到可见区域，不自动播放。范围保存或快捷键冲突失败时编辑面板保持打开。
