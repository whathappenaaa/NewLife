## 需要真实设备配合的验收

1. 选择真实麦克风、耳机和标准CABLE Input；在微信选CABLE Output，停止当前音效后使用“测试通话声音”，请对方确认。
2. 在微信中边讲话边播放片段，停止片段后确认本人讲话继续；QQ和Discord同样验证。
3. 使用“一键临时配置”前记录Windows默认通信麦克风；隐藏保持，断开／退出恢复。中途手动换成另一设备时保留新选择。
4. 分别在输出音频增强开／关时连续录音，对比断续与本人回声。展开音频诊断观察丢帧、欠载和缓冲。
5. 使用真实麦克风和系统输出进行长时间混录，检查漂移、静音区间及文件完整性；活动设备拔出、磁盘实际写满和断电仍需配合验证。

本版不改变音频增强、扬声器默认设备、系统音量或Windows“侦听此设备”。默认不监听本人麦克风；本人回声检查Windows侦听和声卡侧音。异常强制结束或断电由下次启动尝试恢复临时通信设置，无常驻守护程序。
