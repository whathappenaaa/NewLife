## 操作与教学

先退出旧版本，然后运行 `artifacts/release-v0.3/NewLife/NewLife.exe`。通过文件夹按钮选择已有MUSIC目录，音乐无需搬动或改名。勾选后批量回收；拖入外部媒体复制导入；拖动波形下方进度轨道定位；拖入头像／背景图片裁剪。跨电脑时同时复制媒体和同名 `.newlife`，等待界面确认保存成功再复制。

VS Code工程已重新打开。教学 [第八至十课](docs/开发流程与练习.md) 解释本轮做了什么、关键代码位置、断点和实际验证步骤。源码和发布版属于不同运行入口，修改源码后需要重新打包才会更新EXE。
